# 不确定性传播相关性分析（实验方法与结果）

## 1. 实验方法论

本实验旨在评估 Benchmark 分数与 LMArena Elo 分数之间相关性的稳健性，通过蒙特卡洛模拟传播测量不确定性。

### 1.1 数据来源与处理
- **LMArena 数据**：使用 `data/raw/lmarena` 目录下对应 Category（如 Math, Coding）的 `data.csv` 文件。
  - **Elo 值**：使用文件中的 Elo 得分（或 Score）作为均值。
  - **不确定性 (Sigma)**：利用文件中提供的 95% 置信区间 (CI) 推导标准差，公式为 `sigma = CI / 1.96`。
- **Benchmark 数据**：使用各 Benchmark 的原始得分。
  - **不确定性**：假设 Benchmark 得分服从二项分布，标准差由题目数量决定：`sigma = sqrt(p(1-p)/N) * 100` (其中 p 为得分/100，N 为题目数)。

### 1.2 模拟过程
- **模拟次数**：对每个 Benchmark 进行 N=10000 次蒙特卡洛模拟。
- **得分扰动**：
  - LMArena Elo：从 `N(Elo, Sigma_Elo)` 中采样。
  - Benchmark Score：从 `N(Score, Sigma_Score)` 中采样（并截断在 0-100 之间）。
- **相关性计算**：在每次模拟中，计算采样后的 Elo 与 Score 之间的 Spearman 秩相关系数 (Rho)。

### 1.3 统计量定义
- **原始 Rho (Orig Rho)**：基于原始数据的 Spearman 相关系数。
- **模拟 Rho (Simulated Rho)**：10000 次模拟相关系数的平均值。
- **模拟 95% CI**：10000 次模拟相关系数分布的第 2.5 百分位和第 97.5 百分位 (`[2.5%, 97.5%]`)。
- **原始 P 值 (Orig P-value)**：基于原始数据的双尾 P 值。
- **模拟 P 值 (Simulated P-value)**：模拟相关系数小于等于 0 的频率（即单尾检验，检验是否存在显著正相关）。

## 3. 简要分析

1. **稳健性**：大部分 Benchmark 的模拟 95% CI 都在 0 以上，且模拟 P 值极低 (<0.05)，说明其与 LMArena Category Elo 的正相关关系是稳健的。
2. **不显著项**：模拟 P 值较大（>0.05）或 CI 包含 0 的项（如 IOI, IFEval），表明在考虑测量误差后，无法确信其与人类偏好（LMArena）存在正相关。
